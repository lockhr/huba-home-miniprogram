# 使用说明

“胡巴家长们”给两位用户提供一个共享生活空间。一个微信账号同一时间只能加入一个空间，服务端负责数据隔离。

## 首次使用

1. 确认当前微信身份并设置昵称。
2. 一人创建空间，点击“复制邀请码”并发送给另一人。
3. 另一人在加入页面粘贴邀请码，核对空间名称后加入。

进入空间后，可以共同管理任务与积分、商城兑换、点菜、生活记录、愿望和家规。小八、课表、OCR 与微信提醒是否显示，取决于部署者是否配置对应能力。

## 离开与注销

- “离开当前空间”只解除自己的成员关系；如果空间只剩你一人，需要先注销共同空间。
- “注销共同空间”会删除双方共享内容。界面要求连续确认两次；双人空间还需要另一位成员同意。清理开始前可以撤销。
- “注销个人账号”只对未加入空间的账号开放。

这些操作与退出微信登录不同。重要内容请先自行备份。

## 隐私与安全

共享内容只应在同一空间的成员之间可见。不要在小八对话、课表截图或记录图片中提交不希望发送到对应云服务的数据。部署者应把数据库设为仅管理端可读写，并定期核查权限与日志。

## 常见问题

- 看不到小八或课表：通常是部署者未开启，不是账号故障。
- OCR 不可用：可继续手动填写课程。
- 邀请码失效：让仍在空间中的成员重新生成。
- 已离开后找不到旧内容：数据仍属于原空间，不会跟随账号进入新空间。
